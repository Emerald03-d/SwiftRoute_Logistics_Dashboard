# SwiftRoute Logistics Dashboard | Power BI

## 📊 Project Overview

The SwiftRoute Logistics Dashboard is an interactive business intelligence project developed using Microsoft Power BI to analyze logistics operations, financial performance, and delivery efficiency.

The dashboard transforms logistics data into visual reports that help users explore revenue, profit, shipment volumes, delivery delays, shipping costs, and performance across different regions and cities.

The project demonstrates how Power BI can be used to monitor key performance indicators (KPIs), identify operational patterns, and support data-driven decision-making.

## 🎯 Project Objectives

The objectives of this project are to:

- Monitor total revenue and total profit.
- Track shipment volumes and delivery delays.
- Analyze late shipment rates.
- Compare revenue and profit across destinations.
- Examine performance across regions and cities.
- Evaluate shipping costs and profitability.
- Analyze delivery status, carriers, package categories, and service types.
- Present logistics performance through interactive visualizations.

## 📈 Dashboard Features

### 1. Executive Overview

The Executive Overview page presents key logistics performance indicators, including:

- Total Revenue
- Total Profit
- Total Shipments
- Total Delay Days
- Late Shipment Rate

It also provides visual analysis of revenue by destination region, profit by package category, carrier performance, delivery status, and destination-level operational performance.

### 2. Operational Performance Analysis

The Operational Performance Analysis page provides a more detailed view of logistics operations through metrics and visualizations covering:

- Average Profit
- Average Revenue
- Average Shipping Cost
- Revenue by Destination City
- Shipment Distribution by Destination Region
- Shipment Distance and Delay Days
- Performance by Customer Type
- Performance by Service Type
- Operational performance across different destinations

### 3. Interactive Filters

The dashboard includes interactive filters that allow users to explore the data by:

- Order Date
- Destination Region
- Carrier
- Service Type
- Package Category
- Customer Type

These filters help users examine different segments of the logistics business.

## 🔍 Business Questions Explored

The dashboard supports investigation of questions such as:

- How much revenue and profit does the business generate?
- How many shipments are handled?
- How significant are delivery delays?
- Which regions and cities contribute to revenue?
- How does profitability vary across package categories?
- How do carriers compare across shipment and delivery metrics?
- How do shipping costs vary by service type?
- Which destinations may require closer monitoring of delivery performance?

## 💡 Business Applications

The dashboard can help logistics decision-makers monitor financial performance, investigate delivery delays, compare regional results, and evaluate shipping costs.

The analysis can also support further investigation into underperforming locations, carrier performance, and opportunities to improve delivery efficiency and profitability.

Specific recommendations should be based on the values and patterns observed in the dashboard.
